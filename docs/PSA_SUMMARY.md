# PSA Summary

**Organization:** Mabeli Technology

**Topic:** Machine Learning-Based Web Attack Detection Using Node.js

**Short explanation:**

Mabeli Sentinel is a Node.js-based cybersecurity system for Mabeli Technology that uses a Python
machine-learning model trained with CIC-IDS2017 to analyze compatible network traffic, identify
normal or malicious behavior, classify likely attacks, store results in MongoDB and provide
real-time alerts and incident investigation through a security dashboard.

**One sentence to remember:**

> Node.js receives the traffic information, the trained AI checks whether it is normal or malicious,
> MongoDB saves the evidence, and Mabeli Sentinel alerts the security team when suspicious activity is detected.
